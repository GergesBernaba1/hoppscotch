🧼 SOAP WSDL Import Features

This demo showcases the new enhanced WSDL import functionality with three powerful features:

Feature 1 Create Sample Requests for All Operations

What this creates:
  • Individual requests for each WSDL operation
  • Pre-filled SOAP envelopes with sample parameters
  • Proper SOAP headers and content-type settings
  • Operation documentation extracted from WSDL
Example generated SOAP envelope: <?xml version="1.0" encoding="UTF-8"?> <soap:Envelope xmlns:soap="http://schemas.xmlsoap.org/soap/envelope/"> <soap:Header/> <soap:Body> <tns:GetWeatherRequest> <!-- Sample parameters for GetWeather --> <parameter1>sample_value_1</parameter1> <parameter2>sample_value_2</parameter2> </tns:GetWeatherRequest> </soap:Body> </soap:Envelope>

Feature 2 Create TestSuite for the Imported WSDL

What this creates:
  • Separate test collection with automated test scripts
  • Response validation tests (status codes, XML structure)
  • SOAP fault detection tests
  • Performance and response time tests
Example test script: // Test script for GetWeather operation pm.test("Status code is 200", function () { pm.response.to.have.status(200); }); pm.test("Response is valid XML", function () { const responseText = pm.response.text(); pm.expect(responseText).to.include('<?xml'); pm.expect(responseText).to.include('soap:Envelope'); }); pm.test("No SOAP fault", function () { const responseText = pm.response.text(); pm.expect(responseText).to.not.include('soap:Fault'); });

Feature 3 Create Web Service Simulation

What this creates:
  • Mock endpoints for each operation
  • Realistic mock responses based on WSDL schema
  • Simulation scripts for offline testing
  • Configurable mock data for different test scenarios
Example mock response: <?xml version="1.0" encoding="UTF-8"?> <soap:Envelope xmlns:soap="http://schemas.xmlsoap.org/soap/envelope/"> <soap:Body> <tns:GetWeatherResponse> <result> <status>success</status> <message>Mock response for GetWeather</message> <data> <temperature>22</temperature> <humidity>65</humidity> <condition>Sunny</condition> </data> </result> </tns:GetWeatherResponse> </soap:Body> </soap:Envelope>

🗂️ File Upload Support

Enhanced WSDL Import Options:
  • ✅ Import WSDL from URL (existing)
  • ✅ Import WSDL from file upload (.wsdl, .xml files)
  • ✅ Automatic collection naming from filename
  • ✅ File validation and error handling

💡 How to Use

  1. Go to SOAP Collections
  2. Click "From WSDL" button
  3. Choose between URL or File upload
  4. Enter your WSDL URL or upload a .wsdl/.xml file
  5. Enter a collection name
  6. Select the features you want:
    • ✅ Create sample requests (recommended)
    • 🧪 Create test suite (for quality assurance)
    • 🎭 Create simulation (for offline testing)
  7. Click "Create Collection"
  8. Enjoy your automatically generated SOAP requests with enhanced functionality!
